Eficiencia relativa

La eficiencia relativa compara el error obtenido con el que habría dado un DCA

$$\hat\sigma^2_{\text{DCA}} = \frac{(b-1)\,MS_{\text{Bloques}} + b(a-1)\,MS_E}{ab-1}$$

$$R = \frac{(f_b+1)(f_r+3)}{(f_b+3)(f_r+1)} \cdot \frac{\hat\sigma^2_{\text{DCA}}}{MS_E}$$

con \(f_b = (a-1)(b-1)\) y \(f_r = a(b-1)\). El primer factor es siempre menor que 1: el precio de los \(b-1\) grados de libertad.

Comparaciones y número de bloques

Todo el capítulo 3 sirve cambiando \(n\) por \(b\) y \(N-a\) por \((a-1)(b-1)\)

$$\text{EE}(\bar y_{i.}) = \sqrt{\frac{MS_E}{b}}, \qquad \text{EE}(\bar y_{i.} - \bar y_{k.}) = \sqrt{\frac{2\,MS_E}{b}}$$

En una diferencia, los efectos de bloque se cancelan observación a observación: la cancelación es exacta, y un DCA no puede prometerla.

Lo que no se traduce

Comparar los bloques. No se rechaza un lote de resina: si interesara comparar sus niveles, no era un bloque, era un segundo factor (capítulo 7).

potencia_dbca <- function(a, b, tau, sigma2, alpha = 0.05) {
  gl1 <- a - 1; gl2 <- (a - 1) * (b - 1)
  lambda <- b * sum(tau^2) / sigma2
  pf(qf(1 - alpha, gl1, gl2), gl1, gl2, ncp = lambda, lower.tail = FALSE)
}

Diagnóstico y no aditividad

En un DBCA los residuos contra ajustados sí pueden curvarse

Qué significa la curvatura

Interacción bloque × tratamiento: el efecto del tratamiento depende del bloque. El modelo no tiene término para ella, así que se va al error, lo infla, y el \(F\) de tratamientos se vuelve conservador.

Diagnóstico y no aditividad

La prueba de Tukey gasta un grado de libertad en la interacción más probable

$$y_{ij} = \mu + \tau_i + \beta_j + c\,\tau_i\beta_j + \varepsilon_{ij}$$

$$SS_N = \frac{\left[\sum_i\sum_j y_{ij}\,\hat\tau_i\hat\beta_j\right]^2}{\left(\sum_i \hat\tau_i^2\right)\left(\sum_j \hat\beta_j^2\right)}$$

$$F_0 = \frac{SS_N/1}{(SS_E - SS_N)/[(a-1)(b-1)-1]}$$

Un regresor, un grado de libertad: esa es toda la magia.

Diagnóstico y no aditividad

En el injerto la aditividad aguanta: \(SS_N = 0.197\) de 109.886

La prueba de no aditividad, a mano
no_aditividad <- function(y, trt, blq) {
  A <- tapply(y, trt, mean) - mean(y)
  B <- tapply(y, blq, mean) - mean(y)
  num <- sum(y * A[as.integer(trt)] * B[as.integer(blq)])
  ss_n <- num^2 / (sum(A^2) * sum(B^2))
  tab <- anova(aov(y ~ trt + blq))
  gl_resto <- tab["Residuals", "Df"] - 1
  ss_resto <- tab["Residuals", "Sum Sq"] - ss_n
  F0 <- ss_n / (ss_resto / gl_resto)
  c(SS_N = ss_n, SS_resto = ss_resto, gl_resto = gl_resto, F0 = F0,
    p = pf(F0, 1, gl_resto, lower.tail = FALSE),
    c_estimado = num / (sum(A^2) * sum(B^2)))
}
round(no_aditividad(injerto$y, injerto$presion, injerto$lote), 6)

Diagnóstico y no aditividad

Si la aditividad se rompe: transformar, buscar el culpable o replicar

Transformar

Una interacción multiplicativa es aditiva en logaritmos. En el simulador, \(p\) pasa de 0.0000 a 0.6639.

Buscar el culpable

A veces la fabrica una sola observación, como en el EG-19. Se mira antes de transformar.

Replicar

Con más de una observación por celda, la interacción se estima sin suponerle forma: factorial con bloques, capítulo 7.

El bloque como factor aleatorio

Con lotes al azar, el bloque deja un solo parámetro: \(\sigma^2_\beta\)

$$\beta_j \sim \text{NID}(0, \sigma^2_\beta), \qquad \hat\sigma^2_\beta = \frac{MS_{\text{Bloques}} - MS_E}{a} = \frac{38.45 - 7.33}{4} = 7.78$$

El mismo componente por REML
library(nlme)
reml <- lme(y ~ presion, random = ~ 1 | lote, data = injerto,
            method = "REML")
round(as.numeric(VarCorr(reml)[, "Variance"]), 6)
#> [1] 7.781166 7.325750

El \(F\) de tratamientos y las comparaciones no cambian. La correlación intraclase, \(7.78/(7.78 + 7.33) = 0.515\), es la correlación entre dos observaciones del mismo lote.

El bloque como factor aleatorio

Sin efecto de bloque, el estimador ANOVA sale negativo en el 55 % de los casos

$$P(\hat\sigma^2_\beta < 0) = P\!\left(F_{b-1,\,(a-1)(b-1)} < \frac{1}{1 + a\,\sigma^2_\beta/\sigma^2}\right)$$

Cuando pase, se reporta \(\hat\sigma^2_\beta = 0\) y se dice que se truncó.

Ciencia de datos

El bloque tiene otros cuatro nombres

Muestreo estratificado

Se muestrea dentro de estratos homogéneos. El estrato es el bloque, y la ganancia de precisión se calcula igual.

Test A/B por bloques

En vez de una moneda por usuario, las variantes se reparten dentro de cada segmento: país, plataforma, cohorte.

Emparejamiento causal

Comparar cada tratado con un control parecido es bloquear a posteriori, con los datos ya recogidos.

Validación por grupos

El caso menos obvio: varias filas por paciente, por lote o por usuario. Es la pregunta siguiente.

Lo que se llevan hoy

  • \(R\) dice cuántas réplicas necesitaría un DCA; bloquear en balde cuesta poco
  • El capítulo 3 vale con \(b\) en el lugar de \(n\); los bloques no se comparan

  • Si falta un dato, los bloques primero; si son una muestra, se estima \(\sigma^2_\beta\)
  • Con datos agrupados, el modelo se valida partiendo por grupo
